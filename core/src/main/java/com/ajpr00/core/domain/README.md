# Domain Layer

La capa más estable y pura del proyecto.  
Define el "qué" hace la app, no el "cómo".

## Contiene
- Modelos de dominio
- Interfaces de repositorios
- Casos de uso (si se usan)

## Misión
Establecer reglas de negocio y contratos entre capas.

## No debe contener
- Android
- Firebase
- CredentialManager
- DataStore
- Composables
- ViewModels
