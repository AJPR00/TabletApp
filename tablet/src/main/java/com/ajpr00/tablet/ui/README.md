# UI Layer

Todo lo que el usuario ve y toca.

## Contiene
- Pantallas completas (screen/)
- Componentes reutilizables (components/)
- Navegación (navigation/)
- Temas y estilos (theme/)

## Misión
Mostrar datos y reaccionar a eventos del usuario.

## No debe contener
- Lógica de negocio
- Lógica de autenticación
- Acceso a repositorios
- Firebase, CredentialManager, DataStore
